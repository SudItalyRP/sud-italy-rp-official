SUD ITALY RP — FILE AGGIORNATI

Contenuto:
- index.html: pagina aggiornata, ordine reparti corretto e caricamento/scorrimento ottimizzati.
- images.js: mappa leggera che collega le immagini agli asset WebP.
- assets/: immagini ottimizzate e migliorate, incluse quelle di Bar della Piazza, Autogrill e hero.

INSTALLAZIONE:
1. Estrai tutto il contenuto dello ZIP.
2. Carica index.html, images.js e l'intera cartella assets/ nella stessa directory del sito su GitHub.
3. Mantieni la cartella assets allo stesso livello di index.html e images.js.
4. Pubblica/aggiorna GitHub Pages come fai normalmente.

Non caricare soltanto index.html e images.js: la cartella assets è necessaria per visualizzare le immagini.
